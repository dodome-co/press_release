# プレスリリースサポートアプリ 仕様書（たたき台 v0.2）

元資料：仕様書の元となる文書.md を整理・補強したもの。`【要確認】` は未決事項（9章に一覧）。

## 1. 概要

クライアント（企業）が日時・場所・写真などを入力するとプレスリリース（ドキュメントファイル）を自動作成でき、さらに有料で取材会の企画支援・同行・投げ込み代行を依頼できる Web アプリ。管理者は、作成された書類と依頼内容を確認する。

- 技術前提：Python / Flask、決済は Stripe（元資料より）
- 利用者：クライアント（広報担当・中小企業など）、管理者（運営側）

## 2. 目的・背景

- プレスリリースの作り方・配り方（投げ込み）が分からない企業を支援する。
- 書類作成は無料で提供し、有料の周辺サービスで収益を得る。
- 【要確認】想定する主な顧客像（業種・規模）と、解決したい具体的な困りごと。

## 8. 非機能要件

- **セキュリティ**
  - パスワードはハッシュ化して保存する。CSRF 対策を入れる。
  - 他人の書類・注文は参照不可（所有者チェック）。
  - アップロードは MIME・拡張子・サイズに加え、画像として開けるか検証する。保存名はランダム化する。
  - 管理者はコマンドでのみ作成する。
  - Stripe の秘密鍵・Webhook シークレットは環境変数で管理し、Git に含めない（`.env` は `.gitignore`）。Webhook は署名検証する。
- **決済**：支払い確定は Webhook のみ。同じイベントを2回受けても二重処理しない（冪等性）。
- **環境**：Python 3.x、Flask。開発時のメールはログ出力。【要確認】DB、ホスティング先。
- **個人情報**：電話番号・住所を扱うため、プライバシーポリシーと利用規約のページが必要。
- **テスト**：認証・アクセス制御・アップロード検証・Webhook を優先して自動テスト化する。
