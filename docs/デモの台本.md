# デモの台本（ねたもと。）

発表日：2026-11-22。デモは約3分（時間が足りなければ、★の場面だけ）。

## 0. 発表の前に（準備チェック）

- [ ] VM を最新にする（`ssh press-vm` → `sudo /opt/press-release/deploy/update.sh`）
- [ ] デモのデータを作り直す（バックアップのあと `flask reset-demo --yes`）。会員3人のうち、3人目は「何もない新規会員」
- [ ] ブラウザは Chrome（音声入力は Chrome / Edge）。https のアドレスで開く（http だとマイクが使えない）
- [ ] Nginx の合言葉（Basic 認証）を入力済みにしておく
- [ ] ウィンドウを2つ：①クライアント（通常）②管理者（シークレットウィンドウ。同じブラウザだとログインが混ざる）
- [ ] マイクの許可、スピーカーの音量、会場の Wi-Fi を確かめる
- [ ] 保険：完成した PDF（承認済みのサンプル）と、画面のスクリーンショットを、手元に置く
- [ ] パスワードは、この資料に書かない（手元のメモで持つ）

## 1. 流れ（★は外せない場面）

| 時間 | 場面 | 見せること |
| --- | --- | --- |
| 0:00 | トップページ | キャッチコピー「あなたのいいもの、ニュースの種に育てます。」 |

## 2. 場面ごとの台本

### ① トップ（20秒）
- 画面：トップページ
- 話す：「これが『ねたもと。』です。商品やサービスを持つ地域の企業が、記者に取材してもらうためのプレスリリースを、AI と元記者の二人三脚で作ります。」

### ② 日時・場所を入れる（30秒）
- 操作：クライアントでログイン → 「プレスリリースを作る」→ 新しい書類 → 日付・開始時刻・場所を入力 → **必ず「保存する」**
- 話す：「日時と場所は、記者がいちばん先に見るところなので、フォームで確実に入れます。AI はここを聞き直しません。」
- 注意：保存しないと、チャットは「先に保存してください」と返す。

### ③ AI とのチャット（40秒）
- 操作：マイクのボタンを押して、話す。例：「新しい栗ようかんの試食会をします」「岩手の栗を使った、昔ながらの製法です」
- 話す：「LINE のように会話します。AI は、何を・なぜ・伝えたいことを、聞き取ります。音声でも入力でき、返事は読み上げます。」
- 見せる：土日や午後遅い開始だと、AI が「平日の方が好まれますが、どうしますか」と聞く（記者の経験を、ルールにしたもの）。
- 話す：「AI は事実を作りません。聞いたことだけで書きます。」
- 完了すると、「写真をアップロードしてください」と案内が出る。

### ④ 写真・プレビュー・提出（20秒）
- 操作：写真を追加 →「プレビューへ」→ 提出
- 話す：「ここまでが、クライアントの作業です。広報に詳しくなくても、ここまで来られます。」

### ⑤ 管理者の確認（60秒）
- 操作（別ウィンドウ）：`/admin/login` でログイン → 提出された書類
- 見せる：チャットの記録／AI が出したタイトル＋サブタイトルの3案／「この案を使う」／要旨（前文）
- 話す：「ここが元記者の出番です。AI の案から、記者に刺さるものを選び、要旨を直します。空の要旨では承認できません。AI は下書き、最後の判断は人です。」
- 操作：「承認」→ 「A4 1枚に収まっています」を指す
- 話す：「承認の時点で PDF ができます。文字が多ければ、自動で小さくして、1枚に収めます。」

### ⑥ クライアントで PDF（30秒）
- 操作：クライアントのウィンドウ → 承認された書類 → PDF のプレビュー → 1か所直す → ダウンロード
- 話す：「承認されたあとも、ダウンロードの前に、自分で確かめて直せます。直すと PDF が作り直され、誰が直したかも記録されます。」

## 3. うまくいかないとき

| 症状 | 対応 |
| --- | --- |
| AI の返事が遅い | 「いま AI が考えています」と間をつなぐ。目安：質問は3〜5秒、まとめは15〜20秒 |
| AI が応答しない・エラー | 準備した完成 PDF とスクリーンショットで続ける。「通信が不安定なので、事前に作ったものをお見せします」 |
| マイクが使えない | 文字で入力する（機能は同じ） |
| ログインできない | 管理者とクライアントの入口は別。`/admin/login` か `/login` かを確かめる |
| 画面が崩れた | 再読み込み。だめなら、スクリーンショット |

## 4. 想定質問と答え（短く）

- **AI は間違えませんか？** 事実を作らないよう指示し、さらに元記者が必ず確認・承認します。承認しないと PDF は出ません。
- **費用は？** 試算では、1件のリリースの AI 費用は数十円です（今の見込み。実績で確認します）。
- **個人情報や秘密は？** 他人の書類は見えません（存在も分からない）。パスワードはハッシュで保存。AI の鍵はサーバーの設定だけに置き、コードや Git には入れていません。
- **決済は？** Stripe で作ってありますが、今回のデモでは動かしません（テストモードのみ）。
- **誰が運営？** 元地方紙の記者と、動画編集者の姉弟です。
- **なぜ PDF？** 記者に送る形として、見た目が崩れず、そのまま送れるからです（日本語フォントを埋め込んであります）。
